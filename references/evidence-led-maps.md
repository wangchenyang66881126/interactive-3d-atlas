# 有依据的建筑与机场地图

地图不是把产品总成改名。核心是平面拓扑、楼层和设施关系；三维高度是帮助阅读的表达。

## 建立底图证据

以机场／运营方当前导航入口链接的平面图、服务页和运营方说明为主要证据。查阅日期与资料发布日期分别记录。新上传或新抓取的 PDF 可能仍使用旧分区，不以日期或搜索摘要单独决定有效性。

读取 PDF 地图时使用可用的 PDF 工作流：抽取文字并渲染相关页面核对门号、岛台、图例和连接线。纯文本无法可靠表达哪个标志在哪条连廊、哪个号码属于别的楼层。确认参考图是否旋转、分为多页或含不同楼层的插图。

先画确定的公众区、安检、限制区、候机指廊、端部候机厅和换层连接。不要把比例简化变成拓扑变化：两处独立安检不合并成一整条；弯折连廊不变成直线捷径。

### 资料冲突的处理

1. 区分航站楼旧称、新名称、运营范围和楼层；旧 T1/T3 分界不一定仍是当前导览边界。
2. 让当前图决定图面范围，让运营方服务页提供具体设施地标；记录旧称映射，避免误认为不同地点。
3. 以明确的门号／登机口／值机岛地标标注“附近”或“对面”，不要从一句描述推导精确房间边界。
4. 无法定位的重要设施继续找运营方证据。若用户需要保留未定位条目，把它放在设施目录并注明位置待确认，不随意落点。

## 点位数据

为每个地点保持稳定 ID，数据至少表达：名称、类别、相对坐标、所在楼层或换层属性、安检前后、来源。可选加入附近地标、官网列示开放时间、电话和使用条件。

```ts
type PlaceInfo = {
  id: string;
  name: string;
  category: string;
  x: number;
  z: number;
  zone?: '安检前' | '安检后';
  locationKind: '同层位置' | '换层入口方向' | '未定位';
  landmark?: string;
  sourceId: string;
  // source 记录 URL、查阅时间、适用楼层、位置依据。
};
```

坐标是示意坐标时在地图说明中讲清楚，不展示伪精确的距离或步行时间。未接入室内定位、施工与实时运营数据时，不称为实时导航。

## 门、值机岛与换层

- 区分公众入口的“几号门”和空侧“Bxx 登机口”；出发层不得混入到达层入口。
- 值机区字母数量不等于物理岛台数量。图中同一个字母出现两个岛台时，按同一区域的两个岛台表达，不编造新的官方编号。
- 岛台可补低台面、外向柜台、内部传送带、端部柜台及悬挂标识；示意柜台数不能被描述为现场完整库存。
- 远机位登机口、另一楼层的母婴室等，使用当前层可辨认的换层入口方向并明确目标。不把目标房间或登机口本体平移到当前层。
- 图层展开只分离底板、建筑设施与标注的显示高度，不改变点位 x/z 拓扑，也不把展示层误称为真实楼层。

## 设施完整性与可见性

按用户范围核对母婴、贵宾／航空公司休息室、问询、卫生间、急救、寄存、打包、充电、ATM 等类别。不是每个地图都必须具有这些设施；必须有来源才落点。无障碍属性也需图例或运营方支持。

“服务点看不到”有两种不同原因：未录入，或存在却被缩放逻辑隐藏。先看数据，再看显示策略。重要设施应在总览保留可识别符号，放大时显示更多文本；类别筛选后提升该类标注优先级。

为母婴、休息室、医疗等采用独立符号和颜色；不要只靠颜色区分。根据实际屏幕投影做文字避让，选中点优先，重复且低优先级文字可以暂时收起，仍保留符号或目录入口。

设施详情应回答：在哪里、安检前还是后、是否换层、何时开放、是否需资格、资料来自哪里。贵宾接待中心、付费／资格休息室和公共座椅区不能混称。官网列示的开放时间不是当前正在营业状态。

筛选、搜索列表、地图标记、选中详情使用同一份点位数据和状态。过滤后选择被隐藏的点位，应明确恢复对应分类或说明不可见；不要出现列表选中了而地图永远找不到的状态。

## 机场案例资料入口

以下是 2026-09-08 案例查阅入口，后续制作必须重新核对适用性：

- [杭州机场乘机指南](https://www.hzairport.com/ride/index.html)：从当前页面解析真正链接的航站楼地图，不盲用记忆中的旧 PDF。
- [机场设施与服务](https://www.hzairport.com/mobile/ride/service.html)：母婴、医疗、行李服务、充电等地标。
- [机场贵宾服务](https://www.hzairport.com/easygo/guest.html)：贵宾接待中心与六号厅的位置说明。
- [厦航休息室](https://www.xiamenair.com/brandnew_CN/travel-ground-rest.html)：航空公司自己的休息室位置。

其他机场替换为其对应的官方来源，不复制本案例的门号和点位。
