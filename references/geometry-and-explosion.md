# 结构与拆解

## 素材和保真边界

高质量外观优先选择匹配版本、可编辑节点和许可明确的 GLB/glTF 或经许可转换的模型。检查资产本体及来源说明，不把名称匹配当成车型匹配。检查单位、包围盒、前向、上轴、法线、材质和层级；保留许可证与修改说明。生成图片适合辅助纹理或效果参考，不能替代可以旋转和点选的三维几何。

如果只有外观壳体，可以补充结构示意；为补充部分保留 `schematic` 或等价标记。用户接受类似效果时，可采用同系列基础外观加明确说明的改装特征。若没有足够资产达到用户要求的忠实度，应说清限制或询问关键资产，不将低细节方块模型冒充写实完成品。

## 按语义划分总成

用稳定的 `id` 连接模型节点、名称、系统、拆解变换和详情。推荐数据含义如下，可适配已有字段：

```ts
type AssemblyInfo = {
  id: string;
  name: string;
  system: string;
  parentId?: string;
  schematic: boolean;
  sourceId?: string;
};
// 渲染状态另外持有 node、basePosition、baseQuaternion、baseScale、explodeOffset。
```

拆分优先级：原始语义节点／总成 → 完整连通组件 → 明确边界上的受控几何切割。

不要按三角形中心落在哪个空间盒子就把整车随意切开；这会切碎前盖、轮辐和饰条。需要按连通性拆分时，可建立焊接后的拓扑索引，但输出仍保留原始 UV、法线、颜色、切线、索引及多材质组，避免焊接破坏纹理接缝。按模型尺度选择拓扑容差，不固定沿用上一辆车的阈值。

多材质网格重新分组时必须重建 `geometry.groups` 的 `materialIndex`；不能只复制顶点属性然后挂上材质数组。蒙皮、形变和实例对象不能不加区分地用普通静态网格流程展平。

## 坐标和装配基准

导入后先更新世界矩阵。重设父节点时，选择并一致使用以下一种方式：

1. 保留节点层级和原始局部变换，在总成父节点上施加拆解；或
2. 将几何转换到目标总成的局部坐标：`inverse(target.matrixWorld) * source.matrixWorld`，再将新网格局部变换归一。

不要将世界矩阵烘焙进顶点后又重复施加一次父节点变换。Blender Z-up 与 glTF Y-up 转换时，几何、拆解向量、相机锚点一起核对。只有导出器的坐标变换确认为绕 X 轴 -90° 时，才使用 `(x,y,z) → (x,z,-y)`；不要对已转换数据再转换。

装配基准是稳定状态。每帧从它计算当前状态，而不是累加偏移：

```ts
// offset 与 basePosition 均在 node.parent 的局部坐标中。
node.position.copy(basePosition).addScaledVector(explodeOffset, t);
// 存在旋转展开时，从 baseQuaternion 与目标姿态计算 slerp。
// t 是经过钳制的 0..1 展开参数，平滑过渡使用 delta time。
```

嵌套总成中，子部件的偏移应定义为相对父总成的额外拆解量；不要重复计算父总成已执行的位移。

## 拆解方向

优先符合装配关系和观察需求，避免全部部件向同一方向飞散：

| 对象 | 可读的拆解组织 |
| --- | --- |
| 汽车 | 外壳／车盖向上或外侧；左右车门与车轮分别向两侧；电池层次向下；电驱与热管理按安装位置分离 |
| 飞机 | 机身壳体分层；左右机翼／尾翼对称展开；起落架与舱门向下；发动机沿本机轴展示风扇、核心及喷管层次 |
| 驾驶舱 | 仪表台、遮光板、中控台、顶板、座椅和操纵机构按相互位置适量分开，并提供内部聚焦视角 |

滑杆只是展示装配关系的工具，不自动等同于真实维修拆卸顺序。必要时用分段时序让外壳先让开，再展开内部总成；不要为了零件数而拆散难以辨认的每颗螺钉。

重复的座椅、紧固件等适合实例化，但需保留实例到逻辑部件的映射。汽车旗舰版本的电驱数量、飞机发动机外形和驾驶舱布局需要版本资料支持，不能机械继承旧项目。

## 修复穿模

1. 在装配状态定位相交的具体总成，区分源模型缺陷和后加示意硬件。
2. 检查单位、轴向、重复变换和原点，再调整形状、尺寸或装配基准。
3. 对前盖等曲面，用曲面采样／射线或适用的精确几何检查衡量内部硬件间隙；AABB 交叠只能作为粗筛，不能证明穿模或无碰撞。
4. 修改保存到 `basePosition`／原始几何或装配配置；不要只移动当前帧的节点，否则下次展开或复位会覆盖修正。
5. 检查合拢、典型中间状态和完全展开，再检查复位、选择与隔离后的状态。有碰撞风险的路径按需加密采样；有限采样不能宣称连续路径已获工程证明。

## 内部细节

先保证结构关系，再补材质和功能特征。驾驶舱可细化显示屏、EFB、操纵盘／杆、踏板、推力杆、顶板开关、座椅与约束带，但要匹配目标机型。静态仪表图形需按示意内容处理，不伪造实时飞行数据或可用的操作培训系统。

将隐藏在壳体内的重要系统配合可见性控制、隔离或局部剖开展示。若增加局部视角，相机目标应随该总成的拆解位置移动，不能聚焦到原来的空位置。
