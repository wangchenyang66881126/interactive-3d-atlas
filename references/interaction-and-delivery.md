# 交互、验证和交付

## 场景与界面的职责

保留现有可用架构。新实现通常可将语义数据、三维场景控制和页面状态分开；Three.js/glTF 是合适的默认候选，但不为统一技术栈重建已有项目或固定旧依赖版本。

产品场景通常需要 `explode`、系统可见性、部件选择、隔离、视角、复位与资源释放；地图场景通常需要点位选择、分类筛选、俯视／三维视角、图层展开、缩放与复位。按任务保留或补足核心动作，不为了接口齐全增加用户未请求的功能。

- 选择、筛选和隔离有明确组合规则：可见性来自启用系统与隔离状态的交集。选择来自目录时，必要时恢复其分类，让定位动作真实可见。
- 拖动旋转与点击选择要区分，指针移动超过合理阈值后不当作点击。射线选择忽略被隐藏的对象及其隐藏祖先。
- 高亮可逆；关闭详情或取消选择后回到原材质。实例化总成需要从 instanceId 映射到正确语义对象。
- 滑杆动画每帧从基准算状态，并使用时间步长避免不同刷新率造成不同速度。支持减少动态效果的用户偏好。
- 复位恢复明确的初始状态，包括拆解量、相机、目标、过滤、隔离、选中与自动旋转。初始拆解量按对象与用户偏好决定，不统一固定为 0 或 75%。

## 镜头与布局

以对象的当前包围范围、视口宽高比和侧栏占用空间取景，长翼展飞机与细长机场不能沿用汽车相机距离。聚焦部件／驾驶舱使用当前总成位置；模型展开后不能把相机留在空点。

显示三维工作区、必要控制与有用内容；不要先展示宣传首屏。汽车和飞机沿用已认可的图鉴式界面时，可保留系统列表、部件详情和展开滑杆；机场使用区域／设施筛选和俯视，避免机械式“隔离某扇门”喧宾夺主。

地图符号与文字在缩放时保持可读，但文字不能完全覆盖模型。必要时固定符号像素尺寸、按屏幕投影处理重叠、优先显示选中及关键设施。考虑手机控件、详情面板和地图的相互遮挡；有长详情时让面板内滚动。

## 生命周期与性能

为导入资产检查 HTTP 错误、缺失节点、重复 ID 和非有限坐标；显示有意义的加载或失败状态，不将失败后的空场景称为完成。

按设备限制像素比和阴影分辨率，对重复对象考虑实例化。共享材质与几何不能随意销毁；释放时明确所有权，停止动画、解绑事件与 ResizeObserver，并处理纹理、PMREM、渲染器和控制器。异步导入结束时若组件已卸载，应释放新创建资源。

## 按变化验证

不要把每次换色都变成大型测试工程，也不要用编译通过代替必要验证。

| 变更 | 有意义的检查 |
| --- | --- |
| 换模型／拆总成 | 模型与元数据 ID 对齐、部件分配完整、变换与包围盒有限、关键部件存在、许可记录 |
| 穿模修复 | 装配基准、局部曲面间隙、相关拆解状态、复位后持续生效 |
| 新颜色／灯光 | 修改是否限定目标材质；必要且被允许的视觉观察；阴影投射／接收与范围 |
| 加徽标 | 曲面贴合、方向比例、总成归属、拆解／隐藏同步 |
| 加驾驶舱 | 正确机型特征、聚焦目标、设备可读性、静态仪表的示意说明 |
| 地图修订 | 来源与楼层、ID 唯一、岛台与区域区分、门号集合、坐标与底图关系、换层语义 |
| 加设施／筛选 | 类别与目录一致、关键设施可发现、正确选中点、隐藏分类恢复、详情来源 |

运行项目已有的适当类型检查和生产构建。源代码审查、几何数值检查、WebMCP 状态检查和浏览器视觉检查分别记录，不互相替代。不能因为历史案例未进行视觉 QA 就将“永不视觉检查”写成通用规则；是否执行遵守当前任务和适用技能。

## WebMCP（仅适用环境）

已有工具要沿用同一真实页面状态，不创建单独的假状态。新项目按当前 Sites WebMCP 规则决定是否添加。小型表面一般可以是读取场景、选择已知部件／点位、设置显示配置；不要加不对应用户流程的工具。

特性检测、注册生命周期清理、输入校验和异步状态完成后返回结果都要保留。核对未知 ID、越界拆解值、非法分类不会损坏状态。在支持的 WebMCP 上下文检查注册、合法输入及非法输入，并用读取工具回读；不依赖旧浏览器某个私有 API 名。环境不支持时如实记录，不捏造验证成功。

## 交付分支

### 网页

在当前授权范围内执行适用的建站和托管技能；保留现有项目 ID 和受众配置。复用已有预览标签，发布精确验证的版本并确认终态。不要硬编码本案例托管域名、授权凭据或二进制路径到可复用资源。

### 用户明确要求可编辑模型

这里的“像矢量一样可编辑”通常指保留网格、材质、总成和变换的三维资产。按目标版本确认通用格式导入能力，通常可提供 GLB/glTF 或适当的 FBX／OBJ；需要 `.blend` 时使用实际可用的 Blender 流程生成并检查。OBJ 不能完整保存所有层级、PBR 材质和动画语义。

没有 Cinema 4D 转换环境时，不把改后缀的文件称为 `.c4d`。给出目标软件可导入且保持尽可能多结构的格式，并说明哪些内容需重新连接。网页若运行时生成内部总成，不能只把基础外观 GLB 交出去就声称包含完整展示；需把这些总成一起导出或明确范围。

### 用户明确要求视频／图片

使用当前可用的生成或渲染流程，保持来源和效果边界。静态图片和预渲染视频不算可旋转的三维交互。此 skill 不默认接入视频供应商、购买服务或发送外部消息。
