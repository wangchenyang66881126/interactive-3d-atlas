# 材质、灯光和投影

## 先拆分视觉变量

把背景、地面、环境反射、主光、补光、曝光、各类表面材质独立配置。根据当前反馈只调整相关变量。不要把“深色背景”解释为所有光源和地面一起变黑；用户更晚提出“要看见投影”时，应重新平衡背景与接收阴影的地面。

从参考图确定主色倾向，同时辨别高光、天空反射和阴影。可采集多个漫反射区域作参考，不能把引擎盖上的天空高光直接当作车漆基色。色彩最终受照明、曝光、色调映射和显示器影响，不承诺截图取一个 HEX 就能精确还原真实车漆。

## 材质分工

- 车漆、玻璃、轮胎、金属、碳纤维、座椅和灯具有独立材质逻辑；通过材质名／节点语义限定修改范围，不统一涂黑或涂蓝。
- 哑光黑要提高粗糙度、降低清漆镜面；保留足够轮廓光，不能靠纯黑基色遮蔽细节。
- 深邃蓝或青蓝先保持色相，控制大面积高光与清漆反射，再微调基色明度。白色机身保留表面明暗，避免曝光过高形成一片白。
- 区分颜色纹理与法线／粗糙度等数据纹理的色彩空间。导入资产有高质量纹理时尽量保留。
- 选中高亮使用独立轮廓或可逆材质修改。保存并恢复原始发光色、发光强度等属性，避免选过之后永久改变车漆或仪表。
- 透明材质的排序、深度写入、厚度与双面显示按资产需要处理；不要把 `DoubleSide` 或 `depthWrite=false` 当作修复所有表面问题的开关。

下面是历史案例起点，不是跨引擎或新模型必须使用的“正确参数”：

| 风格 | 颜色与物理材质起点 |
| --- | --- |
| Model 3 哑光黑 | `#101113`，roughness 0.84，metalness 0.04，clearcoat 0 |
| SU7 深青蓝车漆 | `#087e98`，roughness 0.28，metalness 0.42，clearcoat 0.8，clearcoatRoughness 0.23 |

灯光、色调映射和资产不同，需要重新调节；用户指定的效果优先。

## 顶部打光

使用宽而柔和的反射形状，沿车顶、引擎盖或机身曲率产生可读的渐变。把顶部反射板的位置、大小、亮度与负责投影的光源分开控制：用于 PMREM 的发光板提供反射，不会自动在主场景产生实时阴影。

如果顶部像一条刺眼白斑，先扩大或移动反射板、降低亮度、适度增加 clearcoat roughness，再判断是否需要改曝光。不要先把整车压暗。若车身变得灰暗发闷，检查补光和环境反射是否不足，而不是直接将颜色推向亮青。

## 可见的投影

地面需要 `receiveShadow`，相关几何需要 `castShadow`，合适的光源需要启用阴影。用有亮度余量的深灰接收面和适度斜向主光，让接触位置及分离高度能被看见。

按对象装配和展开后的包围范围设置阴影相机，不沿用上一辆车的世界坐标参数；避免展开部件离开阴影覆盖范围。相机范围过大会降低阴影有效精度，分辨率、bias、normalBias 按尺度调整。过大 bias 会让部件显得悬浮，过小则产生阴影痤疮。

零件向下展开时，检查是否穿过地面。优先规划展示间隙；确需下移展示地台时，作为明确、确定的展示状态计算，并在复位时恢复。不要用隐藏地面来代替检查。

## 标志与表面贴合

从用户提供或适当来源获取正确标志，保留必要归属。优先复用模型已有可识别徽标；新增标志时核对前后位置、比例、方向及色彩。

曲面徽标可用贴花或细分贴面投射到目标曲面，沿表面法线保留与模型尺度匹配的微小间隙，避免穿入曲面和 z-fighting。射线要限定目标总成，避免误落到挡风玻璃或内部零件。徽标与所属车盖／车身总成建立父子关系，展开、隐藏、隔离时同步。

## 反馈诊断

| 反馈 | 先检查 | 修正后的观察目标 |
| --- | --- | --- |
| 太亮、塑料感 | 反射板面积与能量、清漆、曝光 | 曲面有高光但主色仍明确 |
| 太暗 | 环境、补光、地面和背景关系 | 车漆、轮胎、玻璃能分开读 |
| 看不到阴影 | 投射／接收开关、阴影相机、地面亮度 | 装配及拆解状态都有层次 |
| 顶部白斑 | 反射板方向、粗糙度 | 顶部亮度连续，不抹掉轮廓 |
| 标志漂浮或穿模 | 曲面投射、法向间隙、父节点 | 全部展示状态保持贴合 |

需要视觉验证时按照当前任务允许的方式进行；数值检查只证明参数或几何条件，不能代替对外观的观察。
